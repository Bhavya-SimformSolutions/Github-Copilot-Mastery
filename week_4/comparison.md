# Week 4 – Copilot Instruction Scope Comparison

## Repository Scope (.github/copilot-instructions.md)
- Enforced consistent coding standards
- Produced more defensive and explicit code
- Better aligned with team practices

## Workspace Scope (.vscode/copilot-instructions.md)
- Reflected personal coding preferences
- Generated shorter and more concise code
- Favored readability over strict conventions

## Key Difference
Using the same prompt, Copilot output changed noticeably based on instruction
scope, proving that Copilot respects both repository and workspace-level rules.

## Conclusionn
Repository-level instructions are best for team-wide consistency,
while workspace-level instructions are ideal for individual customization.
