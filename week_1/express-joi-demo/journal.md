# Week 1 – Copilot Mastery Journal

## First Impressions
GitHub Copilot integrates seamlessly with VS Code and understands backend Node.js patterns very well. It is especially effective when prompts are specific and contextual.

---

## 3 Prompts That Worked Well

1. "Create a basic Express server with JSON middleware and a health check route"
   - Result: Generated clean and production-ready boilerplate.

2. "Create a Joi schema to validate user registration with name, email, and password"
   - Result: Accurate validation rules with minimal corrections.

3. "Create an Express POST route for /register that validates request body using Joi"
   - Result: Correct middleware flow and error handling.

---

## 3 Prompts That Didn’t Work Well

1. "Create validation"
   - Issue: Too vague, Copilot generated unrelated examples.

2. "Handle user data"
   - Issue: Lacked context, resulted in incomplete logic.

3. "Make this better"
   - Issue: Copilot needs explicit intent (performance, readability, security, etc.)

---

## Key Learnings
- Copilot performs best with clear intent and constraints.
- Comments act as powerful prompts.
- File context heavily influences suggestion quality.
