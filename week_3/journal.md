# Week 3 – Chat vs Inline Copilot

## When Chat Is Better Than Inline Copilot

- Explaining existing code
- Debugging runtime issues
- Refactoring with reasoning
- Cross-file updates

## When Inline Copilot Is Better

- Writing boilerplate
- Simple functions
- Fast iteration

## Key Insight

Copilot Chat acts like a debugging partner, while inline Copilot acts like
an autocomplete engine.
